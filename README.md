# Meal Planner

A Flutter mobile app for planning weekly meals with Firebase authentication.

## Features

- Email/password sign up & login with email verification
- Weekly meal planner (Monday–Sunday)
- Browse meals per day, view ingredients
- Add meals manually or search via API
- Delete meals from any day
- Logout from any screen

## Tech Stack

- **Flutter** 3.x / Dart SDK ^3.10.8
- **Firebase Auth** — email/password authentication
- **HTTP** — meal API integration
- **FlutterToast** — user feedback
- **Hive** — local storage (included, not yet active)

## Getting Started

### Prerequisites

- Flutter SDK installed
- Firebase project with **Email/Password** sign-in enabled
- `google-services.json` in `android/app/`
- `GoogleService-Info.plist` in `ios/Runner/`

### Setup

```bash
git clone <repo-url>
cd flutter_application_1
flutter pub get
flutter run
```

### Firebase Setup

1. Create a project at [console.firebase.google.com](https://console.firebase.google.com)
2. Enable **Authentication → Sign-in method → Email/Password**
3. Download config files and place them as described above
4. The `lib/firebase_options.dart` file is generated by FlutterFire CLI — regenerate it for your own project:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```
